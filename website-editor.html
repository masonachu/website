Website editor

Currently edits the highlighted-projects tiles on the home page. More sections to come.

This tool reads the highlighted-projects grid out of index.html, lets you add, remove, edit and reorder tiles, and writes the result back. Nothing else on the page is touched.

Open website folder is the easy route (Chrome or Edge): pick your website folder once and the tool can save index.html and copy new photos into images/ for you.

Load index.html works in any browser, including Safari. Saving then downloads a new index.html for you to drop into the folder, and you copy any new photos into images/ yourself using the filename shown.

After saving, commit and push as usual. Big tiles take a 2×2 block; small tiles fill in around them automatically, matching the live site.
